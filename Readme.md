# BullshitKing / 瞎掰王

这是一个基于 Flask 和 Socket.IO 的在线多人游戏 Demo，灵感来源于“瞎掰王”玩法。玩家可在浏览器中实时加入同一房间，进行身份发放、倒计时、瞎掰与猜测的互动体验。

## 项目特点

- 基于 Web 的实时多人游戏
- 支持玩家输入用户名加入房间
- 支持“老实人 / 瞎掰人 / 大聪明”角色分配
- 支持游戏开始、倒计时、跳过词条、重置房间等操作
- 使用 Flask + Socket.IO 实现实时消息同步

## 技术栈

- Python 3
- Flask
- Flask-SocketIO
- Bootstrap
- JavaScript / HTML / CSS

## 项目结构

- app.py：Flask 与 Socket.IO 服务器主程序
- templates/index.html：前端页面
- static/：静态资源、样式、图片和词库数据
- static/data.json：游戏词库数据
- socket_old/：旧版 Socket 实现参考代码

## 运行方式

1. 安装依赖

```bash
pip install Flask flask-socketio
```

2. 启动服务

```bash
python app.py
```

3. 打开浏览器访问

```text
http://127.0.0.1:5000/
```

## 游戏说明

- 至少需要 3 人参与，建议 4 人以上体验更完整
- 进入页面后输入用户名即可加入房间
- 游戏开始后系统会随机分配角色：
  - 大聪明：负责引导游戏
  - 老实人：根据卡片内容诚实描述
  - 瞎掰人：编造故事，尽量让人误以为是真实内容
- 游戏中可以设置倒计时、使用教学词库或完整词库，也可以重置房间

## 注意事项

- 当前版本为 Demo，所有玩家共享同一个房间
- 如果出现异常情况，可以刷新页面或使用“强制初始化”按钮重置房间
- 词库图片资源来自游戏相关资源，使用时请遵守相关许可要求
